# ScienceCraft

Sitio web de ScienceCraft: un laboratorio de estadística e investigación dentro de Minecraft para colegios.

Publicado con GitHub Pages en https://sciencecraft-co.github.io/ScienceCraft/

Es una sola página estática (`index.html`, en español e inglés; `?lang=en` abre la versión en inglés). Todas las
imágenes son capturas del mundo de ScienceCraft o figuras hechas para él.

No es un producto oficial de Minecraft. No está aprobado por Mojang ni por Microsoft ni asociado con ellos.
